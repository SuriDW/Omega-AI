# Model Files

This directory should contain the following files for the TODO list application:
- vocab.json - Vocabulary file for the tokenizer
- merges.txt - Merges file for the tokenizer
- llama3-model.model - Trained Llama3 model file

These files are required for the LLM functionality of the TODO list application.
The application will check for these files and display an error message if they are not found.

You can use existing model files from your Omega-AI installation or train a new model specifically for the TODO list application.
